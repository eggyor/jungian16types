# 新增文章與分類標籤

## 新增流程

1. 複製 `templates/文章範本.md` 到 `_posts/`，檔名採 `YYYY-MM-DD-簡短名稱.md`。
2. 填好 YAML Front Matter、摘要、正文和圖片替代文字；檢查日期與時區格式。
3. 理論文章填 `categories: [理論文章]`，並從六個合法 `subcategory` 中選一個。公告用 `categories: [最新公告]`，不填理論文章子分類。
4. `tags` 可填零個或多個主題標籤；沿用 [分類與標籤詞彙表](分類與標籤詞彙表.md) 的既有拼法。
5. 將文章圖片放在 `assets/images/`，在 `cover` 和 Markdown 圖片語法中使用網站相對路徑。文章 slug／網址依目前 Jekyll permalink 設定產生；若有特別要求舊網址，先比照現有文章設定。
6. 儲存並推送到 `main`。GitHub Actions 會更新資料、建置和部署。若分類文章沒有出現，先檢查 `categories` 與 `subcategory` 是否完全相符。

## Front Matter 範例

```yaml
---
layout: post
title: "文章標題"
date: 2026-10-15 12:00:00 +0800
categories:
  - 理論文章
subcategory: 基礎概念101
tags:
  - 哲學/精神分析基礎概念
excerpt: "一兩句摘要，會用於文章卡片與搜尋預覽。"
cover: /assets/images/封面圖片.webp
cover_alt: "封面圖片說明"
---
```

範本內的範例值均須按新文章調整。標籤可省略或留空；不必為了填欄位而硬加不相關標籤。

## 六個理論文章子分類

- 基礎概念101
- 類型描述
- 榮格原文
- 系統對比
- 常見問題
- 站主銳評

前四類由 `theory/index.html` 的概念資料表呈現；點概念按鈕開啟預覽彈窗，再由彈窗按鈕前往文章全文。常見問題和站主銳評是持續更新的文章列表，只列出 `categories` 包含「理論文章」且 `subcategory` 分別完全等於該分類的文章，依日期由新到舊排序。新增文章只要填對欄位即可加入相應列表，不會混入另一類。

## 格式與內容

正文使用 Markdown。可使用標題、段落、粗體、清單、表格、連結和圖片。外部或站內連結可用標準 Markdown：`[顯示文字](https://example.com)`。連結文字右方括號前不要留空白，例如寫 `[內傾邏輯](./post-1537.html)`，不要寫 `[內傾邏輯 ](...)`，否則空格也會成為連結文字的一部分。

```markdown
## 小標題

一般段落，亦可插入 **粗體** 和 [文章連結](/post-1234.html)。

![圖片說明](/assets/images/圖片檔名.webp)
```

文章版型會自動套用共用頁首／頁尾、文章標籤、分享按鈕、相關文章與最新文章區，以及文章 SEO 資料。`scripts/build_related.py` 在每次部署時比較文章標題、摘要和正文用字，產生最多四篇相關文章；這是詞語相似度排序，不是 AI 語意理解。`_data/related_posts.json` 是產物，無須手動編輯。

## 既有文章移植資料

目前移植文章的分類依 WordPress 原文章分類轉為 Jekyll `categories`／`subcategory`，標籤由原站沿用。原移植說明中的文章數量是當時快照，日後新增文章後不再代表目前總數；實際清單以 `_posts/` 為準。
