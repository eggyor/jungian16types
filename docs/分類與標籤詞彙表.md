# 分類與標籤詞彙表

新增文章時請沿用下列完整寫法。文章主分類、理論子分類和主題標籤是不同欄位，不要互相代替。

## 大分類 (`categories`)

- `理論文章`：理論類文章的共同大分類。搭配一個 `subcategory`。
- `最新公告`：公告文章的獨立大分類。首頁公告輪播與關於本站公告區使用此類文章；不應填理論文章子分類。

## 理論子分類 (`subcategory`)

每篇理論文章選一項：`基礎概念101`、`類型描述`、`榮格原文`、`系統對比`、`常見問題`、`站主銳評`。

## 既有主題標籤 (`tags`)

- 哲學/精神分析基礎概念
- 類型描述
- 榮格原文詞條
- 內傾功能/類型
- 外傾功能/類型
- 理性功能/類型
- 功能定義
- 非理性功能/類型
- 內外傾態度
- 情感功能/類型
- 感覺功能/類型
- 邏輯功能/類型
- 直覺功能/類型
- 理性非理性
- 類型功能疊

「最新公告」是與「理論文章」並列的大分類，文章只需設定 categories: [最新公告]，不應把它填入 tags 或 subcategory。關於本站的輪播與 /announcements/ 全部公告頁都會依此分類自動更新；舊標籤網址會轉向公告頁。

網站導覽項目（主頁、類型測驗、煉金工房、關於本站、全部文章等）不是文章分類。新增標籤前先確認沒有意思相同但寫法不同的標籤。標籤索引由 `tags/index.html` 和 `tags/<標籤>/index.html` 提供，新增標籤頁或更改標籤時，也需確認該標籤索引頁能正確列文。

以上標籤清單是既有資料的整理結果；標籤可選填，不必為每篇文章填滿。
