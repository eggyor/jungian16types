# 分類與標籤詞彙表

新增文章時請沿用下列完整寫法。文章主分類、理論子分類和主題標籤是不同欄位，不要互相代替。

## 大分類 (`categories`)

- `理論文章`：理論類文章的共同大分類。搭配一個 `subcategory`。
- `最新公告`：公告文章的獨立大分類。首頁公告輪播與關於本站公告區使用此類文章；不應填理論文章子分類。

## 理論子分類 (`subcategory`)

每篇理論文章選一項：`基礎概念101`、`類型描述`、`榮格原文`、`系統對比`、`常見問題`、`站主銳評`、`人物分析`。

「人物分析」在理論文章頁面中是第七個子分類，網址為 `/theory/people/`。文章仍使用 `categories: [理論文章]`，並設定 `subcategory: 人物分析`；人物分析標籤則填在 `tags`，兩者不可互換。

## 人物分析專用標籤 (`tags`)

以下八種標籤只供人物分析文章使用，其他子分類不要使用：

- `ET分析`
- `EF分析`
- `ES分析`
- `EN分析`
- `IT分析`
- `IF分析`
- `IS分析`
- `IN分析`

人物分析頁會以這八個標籤篩選該分類中的文章；每個標籤也有獨立預覽頁。標籤名稱清單維護於 `_data/person_analysis_tags.yml`，標籤頁位於 `tags/<標籤>/index.html`，共用 `_includes/person-analysis-tag-page.html` 呈現文章標題、摘要與日期。標籤索引頁 `tags/index.html` 會將這八種標籤排在其他標籤之前。

既有主題標籤可按文章內容選用。以上列表是原有標籤；人物分析專用的八種標籤另列於前一節。

「最新公告」是與「理論文章」並列的大分類，文章只需設定 categories: [最新公告]，不應把它填入 tags 或 subcategory。關於本站的輪播與 /announcements/ 全部公告頁都會依此分類自動更新；舊標籤網址會轉向公告頁。

網站導覽項目（主頁、類型測驗、煉金工房、關於本站、全部文章等）不是文章分類。新增標籤前先確認沒有意思相同但寫法不同的標籤。標籤索引由 `tags/index.html` 和 `tags/<標籤>/index.html` 提供，新增標籤頁或更改標籤時，也需確認該標籤索引頁能正確列文。

除人物分析文章應使用相符的人物分析標籤外，其他主題標籤仍可選填，不必為每篇文章填滿。`/post-3399.html` 是人物分析頁長期置頂文章，依設定不加任何標籤。
