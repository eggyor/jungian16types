# 每日瀏覽統計設定

網站已支援 Google Analytics 4（GA4）。完成下列設定並部署後，即可在 GA4 查看每日瀏覽量與各頁面的流量。

## 1. 建立 GA4 資源並取得測量 ID

1. 前往 [Google Analytics](https://analytics.google.com/) 並登入 Google 帳戶。
2. 建立 Analytics 資源，並為網站建立「網頁」資料串流；網站網址填 `https://jungian16types.com`。
3. 從資料串流詳細資料複製測量 ID，格式為 `G-XXXXXXXXXX`。

## 2. 啟用網站追蹤

在儲存庫根目錄的 `_config.yml`，將 `google_analytics_id` 設為你的測量 ID：

```yml
google_analytics_id: "G-XXXXXXXXXX"
```

提交並推送到 `main`，等待 GitHub Actions 建置及發佈完成。這項設定會將 GA4 標籤加到使用共用 SEO 頁首的網站頁面。未填 ID 時不會載入追蹤標籤。

## 3. 查看每日瀏覽量

1. 開啟 GA4，選擇剛建立的資源。
2. 進入「報表」→「參與」→「網頁和畫面」。
3. 在右上方選擇日期範圍；報表圖表可按日查看「瀏覽次數」，表格則會列出各頁面瀏覽量。

新資料串流通常需要一段時間才會出現在標準報表。剛部署後可先用 GA4 的「即時」報表確認網站造訪有送達。GA4 只會從追蹤碼上線後開始收集資料，不會回補過去瀏覽量。
