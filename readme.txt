經典榮格網站｜分類與標籤參考
================================

用途
----
新增文章時，請按本文選用分類與標籤。範本使用 Jekyll 可讀取的 Markdown Front Matter；分類決定文章出現在哪個大分類／小分類頁，標籤記錄文章涉及的主題。

一、文章大分類
--------------
理論文章
  這是理論文章的上層分類。文章若屬於下列六個小分類，請填 categories: [理論文章]，再填一個 subcategory。

最新公告
  公告類文章使用獨立大分類 categories: [最新公告]，不填理論文章小分類。

二、理論文章小分類（subcategory，每篇選一個）
-----------------------------------------------
基礎概念101
類型描述
常見問題
榮格原文
系統對比
站主銳評

原始網站導覽另有主頁、類型測驗、小知識問答、關於本站、全部文章等區域。它們是網站頁面／導覽區，不是上述文章的主分類；若日後要把測驗或小知識問答也改成文章集合，可再建立對應的大分類。

以下標籤用於主頁／關於本站的公告輪播，不是理論文章分類：
最新公告
  公告文章請在 tags 加上此標籤。關於本站頁面會依發佈日期由新到舊，顯示最新 3 篇；此標籤不會讓文章出現在六個理論文章分類頁。

上面的 15 個主題標籤是從原網站文章資料中整理出的既有標籤；「最新公告」是新增的輪播用途標籤。原有 99 篇文章中，有 16 篇沒有標籤；不需要為了填滿欄位而硬加標籤。新增標籤時，請先確認是否已有意思相同的標籤，並沿用同一寫法。

四、範例：Jekyll 可讀取欄位
---------------------------
---
layout: post
title: "文章標題"
date: 2026-10-11 12:00:00 +0800
categories:
  - 理論文章
subcategory: 基礎概念101
tags:
  - 哲學/精神分析基礎概念
  - 內外傾態度
excerpt: "一兩句文章摘要"
cover: /assets/images/封面檔名.jpg
---

正文從這裡開始。

理論文章頁面
------------
範本內的 theory/index.html 會依 subcategory 自動分組顯示文章。文章必須有 categories: [理論文章] 並填對 subcategory，才會出現在對應小分類下面。文章版型會顯示 tags。原 ZIP 的所有 Markdown 檔若要在新網站分類頁出現，也需要按每篇內容補上這些 Front Matter 欄位。

整理來源與計數
--------------
分類名稱和標籤取自 classicjung-offline-complete.zip 中文章頁面的分類與標籤區。原文章分類記錄為：基礎概念101 17篇、類型描述 25篇、常見問題 18篇、榮格原文 25篇、系統對比 9篇、站主銳評 4篇；另有 1 篇公測公告沒有文章分類標籤。原網站「全部文章」頁的分類計數採用不同的文章列表分組，部分文章在多個列表重複出現，因此與單篇文章上的主分類計數不同。
